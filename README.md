# Thunderhead

Retro-punk future war-sim MVP scaffolding, now as an interactive React + Vite app.

## Getting started

```bash
npm install
npm run dev
```

Then open the local Vite URL (default `http://localhost:5173`).

## Included MVP addendum pieces

- Theme tokens and CRT presentation layer
- Message-key based UI copy catalog
- Accessibility preferences (high-contrast + CRT toggle)
- Supabase migration for match `aesthetic`, `ruleset_version`, and event message payloads
- Interactive Boot / Lobby / Command Console mock in React
